## what was built/changed

the interesting commit today isn't code. it's a one-line correction to an instruction file: "shawnos.ai deploys on Vercel, not Railway."

that sounds trivial. it's not.

here's why. when you run ai agent automation tools across multiple projects, each agent session starts by reading its instruction files. those files tell it where to deploy, which accounts to use, which databases to query. if an instruction file says "deploy to Railway" but the site actually lives on Vercel, the agent will confidently deploy to the wrong place. it won't second-guess the docs. it'll execute exactly what it's told and report success.

this happened. an earlier session deployed to the wrong platform because the docs were stale. the fix was one line of markdown. the lesson was bigger: your AI agent setup is only as reliable as the documentation it reads on startup.

the rest was automated. crypto signal pull at dawn. daily tracker scan last night. the Mac Mini's cron jobs doing their thing without supervision.

## observations

there's a pattern I keep noticing with agent-driven development that I think applies way beyond code.

the bottleneck is almost never the agent's capability. it's the accuracy of the context you hand it. a coding agent with perfect instructions and wrong deployment targets will ship perfect code to the wrong place. a sales agent with a great email template and a stale contact list will send beautiful emails to dead inboxes.

the unglamorous work of maintaining instruction files, checking that account references are current, verifying that the system's mental model matches reality... that's the actual infrastructure. not the agent. not the model. the boring documents that tell the agent where it is and what's true.

I think this is why most people who try ai agent automation tools get frustrated and quit. they set up the agent, watch it do something impressive once, then wonder why it starts making weird mistakes a month later. the answer is almost always: something changed in the real world and nobody updated the docs.
